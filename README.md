# Hitori Gotoh — Anime Profile Card

A dark, anime-inspired profile card featuring pink accents, bold typography, and a portrait-focused layout. Built with React and Tailwind CSS

## About the Project

This project is a frontend design experiment inspired by the visual style of *Bocchi the Rock!*. It presents a character profile using a clean component-based structure and a black-and-pink color palette.

The project was created to practice React components, props, Tailwind CSS styling, and layout composition.

## Features

- Anime-inspired visual design
- Dark theme with pink accents
- Reusable React components
- Profile information and hobbies sections
- Custom typography and icons
- Imported image assets

## Built With

- React
- JavaScript
- Tailwind CSS
- Vite (if used in this project)
- Font Awesome

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR-GITHUB-REPOSITORY-URL
   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR-PROJECT-FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Build for Production

To create a production build, run:

```bash
npm run build
```

The build output is typically generated in the `dist` folder when using Vite.

## Customization

You can customize the project by:

- Updating the profile information in `App.jsx`
- Replacing the images in the `assets` folder
- Editing the hobby list in `Hobbies.jsx`
- Adjusting colors, typography, spacing, and layout using Tailwind CSS
